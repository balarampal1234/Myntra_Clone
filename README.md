# Myntra Clone

A full-stack clone of the Myntra website, designed to replicate its core functionality and features. The project consists of a backend for managing data and a React-based frontend for the user interface.

---

## Features
- **Frontend**: A responsive and interactive UI created with React.
- **Backend**: Node.js backend with JSON data for items.
- **Routing**: Dynamic routing for different pages and components.
- **State Management**: Efficient state management using a custom store.
- **Data Handling**: Items stored in `items.json` for seamless data fetching.

---

## Tech Stack
- **Frontend**: React.js
- **Backend**: Node.js
- **Build Tool**: Vite.js
- **Styling**: CSS for responsive design
- **Routing**: React Router for navigation
